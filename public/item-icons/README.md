# Item category icons

These PNGs are a restrained rounded-line adventure-fantasy icon set for the maintained item
categories. They use recognizable world objects and light whimsical details without ornamental RPG
frames or category-specific colors. They are separate from the earlier SVG exploration in
`docs/mockups/item-category-marks`.

- `light/` contains dark-ink icons for the light application theme.
- `dark/` contains warm-paper icons for the dark application theme.
- Each theme provides 24, 32, 48, 64, and 128 pixel square exports.
- Every PNG has a transparent background.
- Every category is native raster artwork generated specifically for this set rather than traced or
  rendered from SVGs.
- Each category uses one canonical design with the restrained detail level established at 32px. The
  same geometry is resized, sharpened, and recolored for every export so details do not appear or
  disappear between sizes.

The directory and filename identify the theme, pixel size, and category. For example,
`dark/32/document.png` is the 32px Document mark for the dark editor theme.
