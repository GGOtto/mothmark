# Item icon catalog

This is the authoritative 100-category item icon vocabulary. Every category has one official
Hugeicons mark. Matching terms may come from an item name, aliases, or tags; the resolver
corroborates those fields as described in [`item-icon-matching-resolver.md`](./item-icon-matching-resolver.md).

The typed sources of truth are [`src/itemIcons/itemIconCatalog.ts`](../src/itemIcons/itemIconCatalog.ts)
and [`src/itemIcons/itemIconLibrary.ts`](../src/itemIcons/itemIconLibrary.ts).
